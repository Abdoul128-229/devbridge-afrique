# DevBridge Afrique 🌍
Plateforme d'échange des développeurs africains, pour les devs, par les devs. Projet de l'équipe DigitalRoot (Bénin) pour le Systalink Challenge 2026.

## Problème
Les développeurs africains travaillent souvent isolés : difficile de trouver de l'aide, des partenaires ou des missions.

## Solution
Un espace communautaire où chaque dev peut publier une demande d'**aide**, un **projet**, une **ressource** ou une **collaboration**, et remercier les contributeurs utiles (« Utile »). Un classement de réputation valorise les meilleurs.

## Stack
HTML, CSS, JavaScript · Supabase (base PostgreSQL + authentification) · Hébergé sur Systalink (site statique)

## Lancer le projet
1. Créer un projet Supabase, exécuter `schema.sql` dans le SQL Editor.
2. Dans `index.html`, renseigner `SUPABASE_URL` et `SUPABASE_KEY` (clé anon public).
3. Ouvrir `index.html` ou déployer sur un hébergement statique.
